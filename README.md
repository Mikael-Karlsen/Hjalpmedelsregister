# Hjälpmedelsregister (Prototyp)

Detta är en **teknisk prototyp** av ett system för att hantera och överblicka besiktningar av hjälpmedel. 

## 🛠 Status & Fokus
Projektet är under aktiv utveckling och fungerar för tillfället som en **frontend-prototyp**. 

* **Nuvarande fokus:** Att bygga ett intuitivt gränssnitt och hantera komplex data.
* **Logik:** Innehåller funktioner för att varna när besiktningsdatum har passerats.

> [!IMPORTANT]
> Just nu körs applikationen helt i webbläsaren utan krav på backend, då fokus ligger på att fastställa användarflödet.

## 🚀 Nästa stora steg
1. **Migrering till React:** För att gå över till komponentbaserad utveckling.
2. **Utökad logik:** Förfina hur användaren interagerar med hjälpmedelslistorna.
