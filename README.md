#Hjälpmedelsregister (Prototyp)
Detta är en tidig prototyp av ett system för att hantera och överblicka besiktningar av hjälpmedel. Projektet används just nu som en teknisk skiss för att sätta logiken och användarflödet i ett verksamhetssystem.

##Status
Projektet är under aktiv utveckling och fungerar för tillfället som en frontend-prototyp.

Nuvarande fokus: Att bygga ett intuitivt gränssnitt och hantera komplex data (boenden, våningar och rum) med ren JavaScript.

Logik: Innehåller funktioner för att varna när besiktningsdatum har passerats samt hantering av detaljpaneler för specifika hjälpmedel.

##Nästa stora steg
Tanken med denna prototyp är att utvärdera flödet innan applikationen byggs om från grunden. Mina kommande mål är:

Migrering till React: För att gå över till komponentbaserad utveckling och mer effektiv state-management.

Utökad logik: Förfina hur användaren interagerar med hjälpmedelslistorna och redigeringsläget.
